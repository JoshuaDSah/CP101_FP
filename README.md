# Obtaining Data
We obtained our data by downloading our data directly from the following data sources.

## Data Sources:
- California_Transit_Routes Shapefile: https://gis.data.ca.gov/datasets/dd7cb74665a14859a59b8c31d3bc5a3e_0/about (California State Geoportal)
- bay_area_counties_polygons Shapefile: https://opendata.mtc.ca.gov/datasets/MTC::san-francisco-bay-region-counties/about (MTC Open Data Catalog)
- tl_2026_06_bg Shapefiles: Block Groups: https://www.census.gov/cgi-bin/geo/shapefiles/index.php?year=2026&layergroup=Block+Groups (US Census Bureau)
- mtc_sb79_tod_zones.geojson: https://opendata.mtc.ca.gov/datasets/MTC::senate-bill-79-transit-oriented-development-zones/about (MTC Open Data Catalog)
